# Backend Service (`backend`)

The **Backend** is a Node.js + TypeScript service that acts as the platform's central API gateway, data persistence engine, and real-time event dispatcher. It manages camera configurations, watchlist records, and incident histories stored in PostgreSQL 16, while consuming high-throughput security events from Redis Streams and broadcasting live alerts via WebSockets.

---

## 1. Directory Structure

```text
backend/
├── src/
│   ├── index.ts               # Express application entrypoint & HTTP server (:4000)
│   ├── config/                # Environment configuration & secrets
│   ├── routes/                # REST route definitions (cameras, watchlists, events)
│   ├── controllers/           # HTTP request handlers & validation logic
│   ├── services/              # Business logic & threat correlation services
│   ├── db/                    # PostgreSQL connection pool and query helpers
│   ├── streams/               # Redis Streams event consumer worker (Week 2-3)
│   ├── websocket/             # WebSocket server for live alert pushing to frontend
│   ├── middleware/            # Error handling, request logging, and authentication
│   └── types/                 # Shared TypeScript interfaces and types
├── dist/                      # Compiled JavaScript output (generated by tsc)
├── package.json               # Node.js dependencies and run scripts
├── tsconfig.json              # TypeScript compiler configuration
└── Dockerfile                 # Multi-stage production container build
```

---

## 2. Core Technologies

- **Node.js 20+ & TypeScript**: High-performance, asynchronous, type-safe runtime.
- **Express.js**: REST API server.
- **pg (`Pool`)**: Managed connection pooling to PostgreSQL 16.
- **ioredis**: Low-overhead client for Redis 7 Pub/Sub and Redis Streams.
- **tsx**: Ultra-fast TypeScript execution and live reload watcher for development.

---

## 3. How to Use & Run

### Prerequisites
Make sure PostgreSQL and Redis are running via Docker:
```bash
docker compose up -d
```

### Installation
```bash
cd backend
npm install
```

### Development Mode (with Live Reload)
```bash
npm run dev
```
Or from the project root:
```bash
make backend
```
The server will start listening on port `4000`.

### Production Build & Run
```bash
npm run build
npm start
```

### Health Check Endpoint
```bash
curl http://localhost:4000/health
```
Response when database and Redis are operational:
```json
{
  "service": "backend",
  "postgres": "up",
  "redis": "up"
}
```
If either infrastructure dependency is unreachable, the endpoint returns HTTP status `503 Service Unavailable`.
