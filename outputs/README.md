# Runtime Outputs & Incident Artifacts (`outputs`)

The `outputs/` directory serves as the local filesystem destination for runtime artifacts, video exports, event logs, and cropped incident snapshots generated by the Border AI analytics pipeline.

---

## 1. Directory Structure

```text
outputs/
├── runs/
│   └── <RUN_TIMESTAMP>/           # e.g., 20261021_224421/
│       ├── annotated.mp4          # Rendered video with bounding boxes, threat tags, & alert banners
│       ├── events.jsonl           # Complete chronological structured event log
│       ├── summary.json           # Aggregated statistics, event counts, and stage latencies
│       ├── manifest.json          # Complete runtime configuration snapshot
│       └── snapshots/             # Pre-annotation evidence frames for THREAT_ALERT incidents
│           └── <ALERT_ID>.jpg     # e.g., e2b3c4d5f6a74b8c9d0e1f2a3b4c5d6e.jpg
```

---

## 2. Artifact Types & Structure

### 2.1 Evidence Snapshots (`snapshots/<ALERT_ID>.jpg`)
Clean, unannotated video frames captured at the exact moment a `THREAT_ALERT` escalates.
- **Pre-Annotation:** Captured before visualizer overlays (boxes/labels) are drawn to ensure forensic clarity.
- **Referenced in Events:** Each `THREAT_ALERT` JSON contains a `details.snapshot_path` pointing to its corresponding snapshot file.
- **Privacy Gating:** Persisted exclusively in `outputs/runs/`, never committed to Git, and can be toggled off via `--no-snapshots`.

### 2.2 Chronological Event Stream (`events.jsonl`)
High-frequency JSONL log containing all pipeline events:
- Geometric observations (`ZONE_ENTER`, `ZONE_EXIT`, `LINE_CROSSING`)
- ANPR plate readings (`PLATE_RECOGNIZED`)
- Watchlist hits (`WATCHLIST_MATCH`)
- Identity and appearance candidates (`FACE_MATCH`, `REID_MATCH`)
- Compound behaviour violations (`ZONE_VIOLATION`, `DIRECTION_VIOLATION`, `LOITERING_VIOLATION`, etc.)
- Composite threat alerts (`THREAT_ALERT`) with scores, levels, and itemized contributions.

### 2.3 Run Telemetry (`summary.json` & `manifest.json`)
- `summary.json`: Ingestion FPS, processing FPS, stage timings (detection ms, tracking ms, rules ms, render ms, write ms), and breakdown of event counts by type and rule ID.
- `manifest.json`: Configuration snapshot including active model, confidence thresholds, spatial zones, behaviour rules, and scoring parameters.

### 2.4 Rendered Output Video (`annotated.mp4`)
Synchronously rendered video showing persistent track IDs, bounding boxes with dynamic threat colors (Yellow for `MEDIUM`, Orange for `HIGH`, Red for `CRITICAL`), threat labels (`T60 HIGH`), and top-screen alert banners.

---

## 3. Git Exclusion & Storage Policy
All media files (`*.mp4`, `*.jpg`, `*.png`) and event logs generated inside `outputs/` are **strictly excluded from Git version control** via `.gitignore` to protect privacy and prevent repository bloat. Only `.gitkeep` files are tracked to preserve folder structure.
